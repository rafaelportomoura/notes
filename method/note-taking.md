# Anotar: da fonte à nota permanente

## O fluxo

```
Captura rápida  →  Nota de fonte  →  Nota permanente  →  Uso (projeto, texto, prática)
(Inbox)            (40-Sources)       (50-Notas-Perm.)
```

## 1. Captura (Inbox)

Qualquer ideia, citação ou tarefa vai para `00-Inbox/` em segundos. Sem formatar. Esvazie 1 vez por semana.

## 2. Nota de fonte (literature note)

Uma nota por livro/artigo/aula. **Com suas palavras.**

Estrutura mínima:

- Referência (autor, título, edição, link/arquivo)
- Pergunta que guiou a leitura
- Resumo em 5–10 linhas
- Ideias principais (3–7), com página
- Citações literais (poucas, entre aspas, com página)
- Objeções e dúvidas
- O que fazer com isso (próxima ação)

## 3. Nota permanente

Uma **ideia por nota**, em **frase completa**, escrita para você daqui a 1 ano.

- Título = a afirmação. Ex.: *"Registrar na hora evita reinterpretação posterior"*, e não *"Registro"*.
- 3–8 linhas explicando com suas palavras.
- **Links** para 2+ outras notas e para a fonte.
- Teste: *eu entenderia isto sem abrir a fonte?*

## 4. Ligar

- Ao criar uma nota, pergunte: **a que isso se conecta?** e faça o link `[[assim]]`.
- Tags só para estado e tipo. Conceitos viram **notas**, não tags.

## Como achar depois

- Busca (`Ctrl+O`, `Ctrl+Shift+F`).
- Notas índice (MOC) por tema, criadas **só quando** um assunto passar de ~10 notas.
- Revisão semanal (ver `rotina.md`).

## Formatos úteis

| Situação | Formato |
|---|---|
| Aula/palestra | Cornell: pistas à esquerda, notas à direita, resumo embaixo |
| Livro denso | Nota de fonte + permanentes |
| Prática (meditação, ritual) | Diário estruturado (data, condições, o que fez, observação) |
| Dúvida | Uma nota de pergunta, que será respondida depois |

## Erros comuns

- **Colecionar** sem processar (Inbox gigante).
- Copiar e colar sem reescrever.
- Muitas pastas e tags no começo.
- Notas sem links.
