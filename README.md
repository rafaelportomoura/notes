# notes

Projeto para aprender **a ler, anotar e lembrar** de forma que as notas sejam consultáveis depois.

> Hipótese: o gargalo não é falta de material, e sim ter **um método simples, repetível e que cabe numa vida corrida**.

## Como usar

1. Leia [decisions/one-vault-or-many.md](decisions/one-vault-or-many.md) (5 min) e decida a estrutura.
2. Copie `template-vault/` para onde quiser e abra como vault no Obsidian.
3. Leia primeiro `method/sustainability.md` (a regra que protege o resto), depois os outros guias de `method/` (um por dia, ~10 min cada).
4. Siga [plan-30-days.md](plan-30-days.md). É curto de propósito.

## Mapa

| Pasta | Conteúdo |
|---|---|
| `decisions/` | Escolhas de estrutura (vault, pastas, tags) |
| `method/reading.md` | Leitura ativa em 3 passadas |
| `method/note-taking.md` | Do rascunho à nota permanente |
| `method/remembering.md` | Recuperação ativa e repetição espaçada |
| `method/routine.md` | Sessão mínima, antiprocrastinação, revisão semanal |
| `method/sustainability.md` | Modos pleno/leve/manutenção, pausa sem culpa, teste dos 3 meses |
| `template-vault/` | Vault inicial com pastas e templates |
| `plan-30-days.md` | Prática guiada |

## Objetivo

Uma prática de estudo **fácil de manter**, que **não vire peso** no futuro. Tudo aqui é julgado por isso.

## Regra única

Se um passo do método tomar mais de 15 minutos por dia, ele é complexo demais. **Simplifique antes de abandonar.**
